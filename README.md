# Roblox Obby Starter

This repository contains a basic Lua script demonstrating how to create a simple obstacle course (obby) in Roblox.

The example script can be found in `game/init.lua` and spawns platforms for players to jump across, a finish area, and a kill brick that respawns players if they fall.

For more information on Roblox development, visit the [Roblox documentation](https://create.roblox.com/docs).
